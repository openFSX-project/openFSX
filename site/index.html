Bring your own FSX installation

openFSX includes no original game resources. The content tools read your local installation without launching or modifying FSX. Aircraft, textures, scenery and SDK binaries stay out of the repository.

What is openFSX?

A project to explore a modern engine for the world of Microsoft Flight Simulator X, inspired by openOMSI. The aim is to read existing content through an independently written runtime and verify compatibility one subsystem at a time.

Today, that means inspecting aircraft definitions and previewing model geometry with diffuse DDS textures. Flight dynamics, scenery and add-on APIs remain ahead.

openFSX / Get started

Get started

Build the research tools from source.

i

No packaged simulator release yet

The current tools inspect content and preview diffuse textured geometry. They cannot fly an aircraft. Build from source with stable Rust and the Windows MSVC C++ build tools.

1. Get the source

git clone https://github.com/openFSX-project/openFSX.git
cd openFSX

2. Inspect your installation

Replace the path with your own FSX folder. Use Windows-1252 only for files in that code page; omit the flag for ASCII/UTF-8.

cargo run -- inspect "D:/Games/FSX" --windows-1252

3. Open a model

The native viewer requires current Vulkan or DirectX 12 drivers. This example selects the Blue/Gold C172 livery from your own installation.

cargo run --features viewer --bin openfsx-viewer -- "D:/Games/FSX/SimObjects/Airplanes/C172/model/cessna172sp.mdl" --lod 150 --texture-dir "D:/Games/FSX/SimObjects/Airplanes/C172/texture.1"

Drag to orbit, scroll to zoom, use arrow keys to rotate, press R to reset and Esc to close.

Verify a change

cargo test --locked
cargo fmt --check
cargo build --locked --features viewer --bin openfsx-viewer
node scripts/build-site.mjs --check

Tests use original synthetic data. Your FSX files remain local and must not be committed.
