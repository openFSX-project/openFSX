# openFSX identity

Original vector artwork: an ascending aircraft leaves an open orbit, paired
with a geometric wordmark and a sky-blue X. The open ring represents an open
project; the cyan tip marks the direction of flight.

- `openfsx-light.svg`: wordmark for light backgrounds.
- `openfsx-dark.svg`: wordmark for dark backgrounds.
- `openfsx-mono.svg`: single-color wordmark, suitable for print.
- `openfsx-icon.svg`: transparent square emblem.
- `openfsx-avatar.png`: square emblem on navy, suitable for a GitHub avatar.
- `openfsx-preview.png`: presentation of the light and dark variants.
- `../../favicon.svg`: small-size emblem on navy.

The SVG files use original path-based letterforms, with no fonts, external
images, scripts or remote dependencies. Regenerate them from the repository
root with `node scripts/build-brand.mjs`.
